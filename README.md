# Trabajo Final de Redes - Bytza

Laboratorio desarrollado con Kathara utilizando OSPF, DHCP, DNS, NAT y HTTP.

## Preparación inicial

Ingresar al directorio del laboratorio:

cd Kathara

Construir las imágenes necesarias:

./preparar_imagenes.sh

Este paso requiere conexión a Internet solamente durante la primera construcción.

## Iniciar el laboratorio

kathara lstart

## Detener y eliminar el laboratorio

kathara lclean
